Amazing Features

🎤

Microphone Input

Real-time pitch detection with smooth tracking and precise matching against target frequencies

🎵

Swara Conversion

Numbers transform into Indian musical notes (swaras). Sing to unlock each digit!

🎮

Obstacle Game

Guide Luttapi through animated barriers while matching pitch targets to reach the result

📊

Pitch Meter

Visual 0-1000 Hz pitch meter with target line for accurate note matching

🎨

Operator Themes

Each operator (+, -, ×, ÷) has unique color schemes and visual themes

⚡

No Installation

Pure web-based game using HTML, CSS, JavaScript - runs instantly on any browser

How It Works

1

Select Numbers

Choose your first number using the calculator interface

2

Pick Operator

Select an operation: +, −, ×, or ÷

3

Second Number

Select your second number to complete the equation

4

Calculate

Press Calculate and allow microphone access

5

Sing Notes

Your numbers are converted to musical notes (swaras)

6

Beat Barriers

Match the pitch to guide Luttapi through obstacles

7

Get Result

Luttapi reaches the finish and reveals your answer!
